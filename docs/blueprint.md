# **App Name**: MediLog

## Core Features:

- Landing Page: Landing page with 'Connect Wallet' button (Metamask / WalletConnect) and Doctor/Patient login selector.
- About Section: Display the benefits of decentralized logs and technologies used (Polygon, IPFS, Ceramic).
- How It Works Diagram: Visually explain how the platform works for doctors and patients.
- Doctor Dashboard: Doctor dashboard: profile, add consultation log (patient address, encrypted summary upload), and view past consultations.
- Patient Dashboard: Patient dashboard: profile, view consultation logs (doctor, timestamp, summary link).
- Optional Feature - Dynamic Integration: Implement a system which will determine whether to generate a video call link. Uses Jitsi. Acts as a tool.

## Style Guidelines:

- Primary color: Strong blue (#3498db), reflecting trust, security, and technology.
- Background color: Light blue (#ecf0f1), creating a clean and modern interface.
- Accent color: Subtle teal (#2ecc71), providing contrast while remaining in harmony with the primary color.
- Font pairing: 'Inter' (sans-serif) for both headlines and body text, ensuring readability and a modern feel.
- Code font: 'Source Code Pro' for displaying wallet addresses or code snippets, improving clarity.
- Use flat design icons related to health, security, and data management to enhance visual understanding.
- Design the layout to ensure logical information hierarchy, improve overall UI.
- Incorporate subtle transitions and loading animations to enhance user experience during data processing and navigation.
